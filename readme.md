# 우주 탐험 대형 타이머 (Timer Web App)

수업 시간 관리, 발표 연습, 모둠 활동, 빔프로젝터 환경 등에서 유용하게 사용할 수 있는 **대형 화면 타이머 웹 애플리케이션**입니다.

---

## 📌 주요 특징

1. **단일 HTML 오프라인 실행**:
   - 외부 서버나 인터넷 설치 없이, 다운로드받은 `index.html` 파일만 더블클릭하면 웹 브라우저에서 바로 작동합니다.

2. **우주 고양이 탐험 테마**:
   - 딥 블루 밤하늘, 반짝이는 별빛 및 유성 효과, 우주복을 입은 귀여운 고양이 캐릭터가 어우러진 시각적 디자인입니다.

3. **GS혜자로운체 웹폰트 & 스티커 POP 디자인**:
   - 둥글둥글하고 두툼한 폰트와 입체 테마 효과로 멀리 떨어진 빔프로젝터 화면에서도 타이머 숫자가 매우 선명하게 보입니다.

4. **직관적인 타이머 제어**:
   - **빠른 선택 버튼**: 5분, 10분, 15분, 30분
   - **수동 입력 & 대형 적용 버튼**: 분/초 단위 입력 후 **🚀 적용** 버튼 클릭
   - **독립 컨트롤**: **시작**, **일시정지**, **초기화** 버튼 지원

5. **마지막 10초 시각적 강조**:
   - 남은 시간이 10초 이하가 되면 글자 색상이 붉은색으로 바뀌며 미세하게 펄스 애니메이션이 실행되어 집중도를 높입니다.

6. **경쾌한 멜로디 알림음**:
   - 웹 브라우저 내장 음원 기술(Web Audio API)을 활용해 외부 MP3 파일 없이 통통 튀는 경쾌한 실로폰/오르골 멜로디를 재생합니다.
   - **🔔 알림음 미리듣기** 버튼으로 언제든 소리를 미리 테스트해 볼 수 있습니다.

---

## 🚀 다운로드 및 컴퓨터 실행 방법 (Windows 기준)

1. 오른쪽 에디터 창 상단/우측의 다운로드 아이콘을 통해 `index.html` 파일과 `readme.md` 파일을 다운로드합니다.
2. 다운로드 폴더에 저장된 **`index.html`** 파일 위에 마우스를 올리고 **더블클릭**합니다.
3. Chrome, Edge, Naver Whale 등 사용 중인 브라우저에서 바로 크고 선명한 타이머가 실행됩니다.
